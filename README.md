# CivicConnectAI 🚀
### AI-Powered Civic Issue Reporting Platform

CivicConnectAI is an AI-assisted web platform designed to simplify civic issue reporting and improve communication between citizens and authorities. It uses artificial intelligence to analyze images of public issues, identify their categories, and help citizens track complaints.

## ✨ Key Features

- **AI Image Detection:** Identifies civic issues such as potholes, garbage, water leakage, and damaged infrastructure.
- **Smart Location:** Detects geographical location using GPS with manual location support.
- **Complaint Tracking:** Generates unique complaint IDs and tracks complaint status.
- **Duplicate Detection:** Identifies potentially repeated complaints.
- **Image Metadata Inspection:** Checks uploaded images for AI-generation indicators.
- **Authority Dashboard:** Enables authorities to review complaints and update their statuses.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Hugging Face Transformers.js
- CLIP Image Classification Model
- Browser Geolocation API
- Local Storage

## 🚀 Getting Started

1. Clone the repository:

```bash
git clone https://github.com/charanv02/CivicConnectAI-Web.git
```

2. Open the project in Visual Studio Code.
3. Run `index.html` using the Live Server extension.

## 💻 Usage

1. Open the website in your browser.
2. Upload an image of a civic issue.
3. Allow GPS access or enter your location manually.
4. Let the AI analyze and classify the uploaded image.
5. Submit the complaint and receive a unique complaint ID.
6. Use the complaint ID to track its status.
7. Authorities can access the dashboard to review and update complaints.
